## The line

> ★ One star. The human only refills my bowl after I have screamed at the empty bowl for twenty minutes, as if the screaming were the refill.

139 characters, one line. A deadpan one-star review in the voice of a house cat: one specific complaint (the food bowl), the human measured by cat standards, with the sting in the last few words — the cat believes the screaming is what summons the food. It keeps the shape of a real review while the logic goes somewhere only a cat would go.

## How it works

`main.ts` (Node 22, stdlib only) writes the line to `/output/entry.txt` via `MAKEFUN_OUTPUT_DIR`, with a guard refusing anything outside the 1–200 character gate.
